A make.fun entry for **Fortune Cookie Funnies for Engineers**: write the
funniest one-line fortune cookie message for a software engineer, 120
characters or fewer.

## The fortune

> Your code will pass review today — by someone who has never read it and never will.

(83 characters.)

## How to run

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (creating `/output` if
needed). Python standard library only — no third-party imports, no
network.
